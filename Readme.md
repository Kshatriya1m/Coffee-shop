Coffee Shop Web Application
A fully functional coffee shop website built using PHP, HTML, CSS, and JavaScript.

Features:

Browse a menu of coffee products

Add items to cart and simulate checkout

User authentication (login / registration)

Responsive and interactive UI

Tech Stack:

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL (or your DB)

This project demonstrates a classic web-app architecture, with full-stack development and basic e-commerce functionality.
